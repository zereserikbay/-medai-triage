## 📌 About the project

MedAI Triage is a prototype that explores how artificial intelligence and rule-based decision support can be used to structure symptom information and identify potentially urgent situations.

The project is designed as an educational demonstration of AI-assisted healthcare technology.

## 🎯 Goal

The main goal is to create a simple and accessible interface where users can describe their symptoms and receive an initial risk-oriented assessment.

The system separates cases into three categories:

- 🟢 Lower risk
- 🟠 Moderate risk
- 🔴 High risk

## ⚙️ How it works

The prototype analyzes the user's description and searches for predefined emergency and urgent-care symptom patterns.

Based on the detected patterns, it provides:

1. A risk category
2. A short explanation
3. A recommendation about seeking medical care
